Runvey connects your Git workflow to your own infrastructure. Its deployment workflow is built around three stages: receive source code, build a container image, and run the service.

## Explore the platform

Start with the [platform concepts](/docs/concepts) to understand repositories, builds, services, and deployments.

## Get started

Visit the [Runvey repository](https://github.com/matchouse/runvey) for the source code and project updates. Installation instructions are not yet available in these docs.
